The Pattern

Persist the idempotency key before the external call, reconcile on timeout instead of blindly retrying. See Idempotency and Timeout.

await db.execute("INSERT INTO idempotency_keys (key, status) VALUES ($1, 'pending')", [key]);
charge = await paystack.charge({amount}, {idempotencyKey: key}); // timeout?
await db.query("UPDATE idempotency_keys SET status='completed' WHERE key=$1", [key]);
